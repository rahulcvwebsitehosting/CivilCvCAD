## Introduction

Plot is a workbench that provides an interface to perform plots.

From CivilCvCAD v0.20 Plot workbench is split into an [external addon](https://github.com/CivilCvCAD/civilcvcad.plot)

## Documentation

Plot documentation can be found on the CivilCvCAD wiki [Plot Workbench](https://wiki.civilcvcad.org/Plot_Workbench) page
