CivilCvCAD offline help

This guide is included with CivilCvCAD and works without an internet connection.

Start drawing

Parametric 3D model

  1. On the Start page, choose Parametric Body.
  2. Select Create sketch, then choose the XY, XZ, or YZ plane.
  3. Draw a closed profile with the line, polyline, rectangle, circle, or arc tools.
  4. Close the sketch and use Pad to turn it into a solid.
  5. Add more sketches and use Pocket, Revolve, Fillet, and Chamfer as needed.

2D drawing

  1. On the Start page, choose 2D Draft.
  2. Use the Draft line, polyline, rectangle, circle, arc, dimension, and annotation tools.
  3. Turn on grid and snapping from the Draft status controls for precise placement.

Architectural model

Choose BIM/Architecture on the Start page, then create walls, structures, slabs, doors, windows, and annotations from the BIM workbench.

Finding tools

The workbench selector changes the available commands:

  • Sketcher creates constrained 2D profiles.
  • Part Design creates feature-based solid models.
  • Draft provides 2D drafting and snapping.
  • BIM creates building and civil/architectural objects.
  • TechDraw creates printable drawing pages from 3D models.

Commands remain disabled until their prerequisites exist. For example, Pad needs a closed sketch, and most Part Design commands need an active Body.

Examples and recovery

The Start page includes sample models that can be opened immediately. If a preference or extension prevents normal startup, choose Help > Restart in Safe Mode. Safe Mode temporarily ignores user configuration; it does not delete files or preferences.

Additional offline documentation can be placed in a local folder and selected under Edit > Preferences > General > Help.
